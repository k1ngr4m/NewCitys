P001 [] 一种基于语义感知的多图时空融合交通流预测方法、系统及介质
P002 [] 技术领域
P003 [] 本发明涉及交通控制系统的技术领域，特别涉及一种基于语义感知的多图时空融合交通流预测方法、系统及介质。
P004 [] 背景技术
P005 [] 交通流预测是智能交通系统进行拥堵预警、信号控制、路径诱导和交通资源调度的重要基础，准确可靠的交通流预测能够显著提升路网运行效率，缓解城市交通拥堵。
P006 [] 现有的交通流预测方法通常以历史交通流量、速度、占有率等数值序列为输入，并结合道路拓扑结构建立时空依赖关系，这些方法难以充分捕捉路网中复杂的空间相关性。随着图神经网络和时序建模技术的发展，基于图卷积、注意力机制、扩散网络的预测模型已能够在一定程度上刻画路网节点之间的空间传播规律和交通状态的时间演化规律。
P007 [] 然而，现有方法在复杂城市路网场景中仍存在以下不足。
P008 [] 其一，许多方法主要依据物理相邻关系或几何距离构建图结构，这类建图方式难以表达物理距离较远但城市功能相近的节点之间的潜在关联。例如，处于不同区域的大型商圈、交通枢纽或通勤走廊可能在特定时间段呈现相似的出行需求或交通模式，仅依赖物理拓扑会遗漏该类长程功能关联，导致模型无法从功能相似的远端节点处获取这些本该有益于辅助预测的信息。
P009 [] 其二，近年来有研究尝试利用预训练语言模型提取交通节点的文本语义信息（如兴趣点描述、区域功能标签），并以此构建语义图结构，其虽能够提供丰富的通用文本语义表示，但通用文本空间与交通动力学空间并不完全一致，直接以文本相似度构建交通图结构，容易引入与交通状态演化无关的字面相似性噪声。
P010 [] 更重要的是，交通流观测序列通常由周期性固有模式和非周期性突发扰动叠加形成。周期性固有模式主要受工作日与周末差异、一天中的时段变化、道路功能属性等因素影响，呈现出相对稳定的日周期和周周期规律；突发扰动则可能由交通事故、临时施工、恶劣天气、大型活动或特殊事件引发，导致交通状态在短时间内剧烈偏离历史规律。现有端到端的混合建模方法往往将上述两种成分共同编码，这导致异常波动被历史周期规律平滑，模型对突发事件响应迟缓，或是突发场景下模型过度依赖历史模式，产生明显的滞后预测。
P011 [] 发明内容
P012 [] 本发明解决了现有技术中存在的问题，提供一种基于语义感知的多图时空融合交通流预测方法、系统及介质，融合节点功能语义、多维空间图结构和交通流解耦表征，在不过度依赖完备外部环境监测数据的情况下提高复杂路网中非平稳交通状态的预测精度和鲁棒性。
P013 [] 本发明所采用的技术方案是，一种基于语义感知的多图时空融合交通流预测方法，包括以下步骤：
P014 [] 获取交通观测数据及对应的交通节点的静态元数据，对交通观测数据进行处理，生成基础时空表征；
P015 [] 根据道路物理连接关系构建物理拓扑图，根据交通观测数据构建动态流量交互图，基于静态元数据生成各交通节点的语义表征及关联交通节点间的语义关联，基于所述语义表征和语义关联建立语义功能图；
P016 [] 将所述语义表征与基础时空表征融合，得到初始节点表征；分别基于物理拓扑图、动态流量交互图和语义功能图对所述初始节点表征进行图卷积，获得对应的三类空间特征；根据时间上下文动态融合所述三类空间特征，得到多图融合特征；
P017 [] 将所述多图融合特征进行时空解耦，分离出表征周期性规律的固有模式特征和表征非周期扰动的突发特征；
P018 [] 将固有模式特征与突发特征融合后解码，得到交通流预测结果。
P019 [] 优选地，利用预训练语言模型提取交通节点的静态元数据的通用语义嵌入，以可学习的映射网络将其转换为面向交通预测任务的语义表征，作为对应各交通节点的语义表征；基于语义表征之间的相似度获取语义关联。
P020 [] 优选地，所述预训练语言模型的主干参数在训练期间保持冻结，所述可学习的映射网络的参数参与预测模型的联合优化。
P021 [] 优选地，基于语义表征之间的相似度建立相似度矩阵，对所述相似度矩阵阈值截断或稀疏化处理，获得用于图卷积的稀疏语义功能图。
P022 [] 优选地，所述动态流量交互图基于自适应滑动时间窗口内的节点交通序列之间的相关性生成，并按预设周期更新。
P023 [] 优选地，三类所述空间特征包括物理空间特征、流量交互特征和语义关联特征，根据时间上下文编码生成对应的门控融合权重，并基于门控融合权重对三类空间特征进行加权融合，得到多图融合特征；
P024 [] 所述时间上下文编码包括用于刻画日内周期的时间段编码和用于刻画周内周期的日期编码；所述门控融合权重由可学习的映射网络根据时间上下文编码生成。
P025 [] 优选地，将三路空间特征按照门控融合权重加权求和时，结合残差连接和均方根归一化，得到时间感知的多图融合特征。
P026 [] 优选地，训练预测模型时，对所述固有模式特征和突发特征施加软正交约束；
P027 [] 训练预测模型的总损失函数与预测误差损失、用于保持解耦特征信息完整性的辅助重构损失及软正交约束对应的正则化损失关联。
P028 [] 一种基于语义感知的多图时空融合交通流预测系统，包括：
P029 [] 至少一个处理器；
P030 [] 存储器，与所述至少一个处理器耦合，所述存储器存储有计算机程序，所述计算机程序被所述至少一个处理器执行时，使得所述系统实现所述的基于语义感知的多图时空融合交通流预测方法。
P031 [] 一种计算机可读存储介质，其上存储有计算机程序，所述计算机程序被处理器执行时实现所述的基于语义感知的多图时空融合交通流预测方法。
P032 [] 本发明涉及一种基于语义感知的多图时空融合交通流预测方法、系统及介质，获取交通观测数据及节点的静态元数据，对观测数据时空嵌入，生成基础时空表征；根据道路物理连接关系构建物理拓扑图，根据观测数据构建动态流量交互图，基于静态元数据生成各节点的语义表征及节点间语义关联，构建语义功能图；将语义表征与基础时空表征融合得到初始节点表征，分别基于三种图结构对初始节点表征图卷积，获得三类空间特征，根据时间上下文动态融合得到多图融合特征，将其时空解耦，分离出固有模式特征和突发特征，将两者融合后解码，得到交通流预测结果；基于方法实现系统和介质。
P033 [] 本发明的有益效果在于：
P034 [] （1）利用节点地理位置、周边兴趣点、道路等级和区域功能属性等静态元数据构建语义功能图，能够补充物理拓扑难以表达的长程功能关联，使模型不仅关注相邻道路之间的传播关系，还能识别功能相似区域之间的同步交通变化；
P035 [] （2）通过可学习领域映射层对预训练语言模型输出的通用语义嵌入进行任务自适应校准，降低字面相似性对交通预测的干扰，使语义邻接矩阵更接近交通动力学关联；
P036 [] （3）构建物理拓扑图、动态流量交互图和语义功能图的并行多图卷积结构，并利用时间上下文门控机制动态调节各图结构的贡献，能够适应不同时段、不同日期和不同交通状态下空间依赖关系的变化；
P037 [] （4）本发明通过基于软正交约束的时空解耦精炼模块降低周期性固有模式与突发干扰特征之间的冗余表达，在保留交通状态非线性耦合弹性的同时增强对异常波动的响应能力，并减少对完备外部环境传感器数据的依赖。

P043 [] 下面结合实施例对本发明做进一步的详细描述，但本发明的保护范围并不限于此。
P044 [] 本发明涉及一种基于语义感知的多图时空融合交通流预测方法，包括以下步骤：
P045 [] (1)获取交通观测数据及对应的交通节点的静态元数据，对交通观测数据进行处理，生成基础时空表征；
P046 [] (2)根据道路物理连接关系构建物理拓扑图，根据交通观测数据构建动态流量交互图，基于静态元数据生成各交通节点的语义表征及关联交通节点间的语义关联，基于所述语义表征和语义关联建立语义功能图；
P047 [] (3)将所述语义表征与基础时空表征融合，得到初始节点表征；分别基于物理拓扑图、动态流量交互图和语义功能图对所述初始节点表征进行图卷积，获得对应的三类空间特征；根据时间上下文动态融合所述三类空间特征，得到多图融合特征；
P048 [] (4)将所述多图融合特征进行时空解耦，分离出表征周期性规律的固有模式特征和表征非周期扰动的突发特征；
P049 [] (5)将固有模式特征与突发特征融合后解码，得到交通流预测结果。
P050 [] 以下结合具体实施例对方法进行说明。约定交通节点是数据集中包含交通状态观测值的传感器节点。
P051 [] (1)获取交通观测数据及对应的交通节点的静态元数据，对交通观测数据进行处理，生成基础时空表征；
P052 [] 本发明，交通观测数据可来源于部署在城市道路或高速路网中的固定检测器，数据项包括交通流量、平均速度和道路占有率中的至少一种；将连续交通观测数据按照时间顺序划分为训练集、验证集和测试集，并对缺失值、异常值和时间戳不一致数据进行清洗。
P053 [] 交通节点的静态元数据包括传感器编号、经纬度、所属区域、道路名称、车道数、道路类型和行驶方向等，这些基础字段可由交通数据集的节点元信息文件提供；节点周边道路等级、兴趣点(POI)类型（如加油站、餐饮、停车入口、学校等，用于描述节点周边的功能环境）及土地利用或区域功能信息可基于传感器经纬度，通过OpenStreetMap等开放地图接口检索补充；道路上下游连接关系可由道路拓扑文件、传感器邻接矩阵或路网连接文件确定。
P054 [] 在一个具体实施方式中，可采用PeMS系列交通数据作为交通观测数据来源，其节点元信息文件提供传感器坐标及道路基础属性，路网邻接文件提供节点间物理连接关系；对于缺少显式兴趣点或区域功能描述的节点，可采用“道路类型、道路等级、上下游连通关系”的模板生成补充描述，以保证每个节点均具有可编码的语义文本。
P055 [] 对于历史交通观测数据，先执行实例归一化以缓解不同节点和不同时间段之间的量纲差异，随后按照预设长度进行时间分块，并通过线性投影将分块后的序列映射为基础时空嵌入，再加入位置编码，从而生成基础时空表征；在具体实施中，实例归一化可采用z-score归一化，即对每个节点的时间序列减去均值除以标准差，保留各节点的均值和标准差用于后续逆归一化。
P056 [] (2)根据道路物理连接关系构建物理拓扑图，根据交通观测数据构建动态流量交互图，基于静态元数据生成各交通节点的语义表征及关联交通节点间的语义关联，基于所述语义表征和语义关联建立语义功能图；
P057 [] 本步骤执行的核心在于语义增强与图构建。
P058 [] (2-1) 物理拓扑图
P059 [] 本发明中，物理拓扑图依据道路连接关系或传感器邻接关系确定，若两个节点位于同一路段上下游或存在直接道路连接，则在物理拓扑图中建立边；该图反映路网的直接物理连接关系。
P060 [] (2-2) 动态流量交互图
P061 [] 本发明中，动态流量交互图基于自适应滑动时间窗口内的节点交通序列之间的相关性生成，可采用皮尔逊相关系数、余弦相似度或其他序列相似性度量确定边权，并通过Top-k选择或阈值截断保留主要交互关系，此为本领域技术人员容易易理解的内容；如以Top-k选择为例，从输入的历史时间窗口内提取各交通节点的交通序列，对节点序列进行标准化处理，计算节点两两之间的相关性，形成相关性矩阵，再对每个节点保留相关性最高的Top-k个节点作为主要交互关系，将保留下来的相关性得分作为边权，得到动态流量交互图；该图可按预设周期更新，以反映交通流交互关系的时变特征。
P062 [] 在一实施实例中，为使动态流量交互图能够同时兼顾平稳交通状态下的相关性估计稳定性和突发交通状态下的响应速度，滑动时间窗口的长度可根据节点交通序列的波动程度自适应调整。设交通节点数为N，第i个交通节点在时刻t的节点交通序列表示为xi(t)，在每个动态图更新时刻t，先基于一个参考窗口计算节点交通序列的波动程度。具体地，可采用节点序列一阶差分的平均绝对变化量作为波动度量，
P063 [] vit=1T0-1τ=t-T0+2txiτ-xiτ-1
P064 [] 其中，T0表示用于计算波动程度的参考窗口长度，vit表示第i个交通节点在当前时刻的波动程度。进一步地，对所有交通节点的波动程度求平均，得到当前路网整体波动程度，
P065 [] V(t)=1Ni=1Nvi(t)
P066 [] 根据整体波动程度V(t)与预设波动阈值θv的比较结果，自适应确定用于生成动态流量交互图的滑动时间窗口长度，
P067 [] Tt=Tlong,Vt<θvTshort,Vt≥θv
P068 [] 其中，Tlong表示较长滑动时间窗口，Tshort表示较短滑动时间窗口，且Tlong>Tshort；当交通序列波动程度较低时，采用较长滑动时间窗口，以提高节点相关性估计的稳定性；当交通序列波动程度较高时，采用较短滑动时间窗口，以增强动态流量交互图对突发变化的响应能力。
P069 [] 在确定当前滑动时间窗口长度Tt后，截取各交通节点在该窗口内的节点交通序列，并计算任意两个交通节点之间的相关性；以皮尔逊相关系数为例，第i个节点和第j个节点之间的相关性得分可表示为，
P070 [] rijt=τ=t-Tt+1txiτ-xixjτ-xjτ=t-Tt+1txiτ-xi2τ=t-Tt+1txjτ-xj2+ε
P071 [] 其中，xi和xj分别表示节点i和节点j在当前滑动时间窗口内的序列均值，ε为防止分母为零的极小常数。
P072 [] 进一步地，根据相关性得分构建动态流量交互图的邻接矩阵。可对每个交通节点保留相关性得分最高的K个关联节点，或保留相关性得分高于预设阈值的节点对；以Top-K筛选为例：
P073 [] Aflow(i,j,t)=max(rij(t),0),j∈TopKi(t)0,otherwise
P074 [] 其中，Aflow(i,j,t)表示时刻t下动态流量交互图中节点i和节点j之间的边权，TopKi(t)表示与节点i相关性得分最高的K个节点集合。由此得到的动态流量交互图能够随交通状态变化自适应更新，在平稳状态下保持较稳定的关联结构，在波动较强或突发状态下提高对短期变化的敏感性。
P075 [] (2-3) 语义功能图
P076 [] 本发明中，利用预训练语言模型提取交通节点的静态元数据的通用语义嵌入，以可学习的映射网络将其转换为面向交通预测任务的语义表征，作为对应各交通节点的语义表征；基于语义表征之间的相似度获取语义关联。
P077 [] 具体地，对每个交通节点，将其静态元数据组织为自然语言描述，例如描述节点所在道路等级、附近主要兴趣点类别、道路功能属性及连接方向；将上述文本输入轻量化预训练语言模型DistilBERT，得到节点通用语义嵌入。
P078 [] 在具体实施中，可学习的映射网络（可学习领域映射层）为可学习的特征变换网络，其包括至少一个线性变换层和非线性激活层，线性变换层用于将通用语义嵌入从通用文本语义空间投影至交通预测任务相关的特征空间，非线性激活层用于增强语义特征的表达能力，进行任务适配后输出交通领域语义特征，其映射矩阵可采用正交初始化或正交约束方式进行参数化，以降低不同语义维度之间的冗余表达，增强交通领域语义表征的区分性和稳定性。在模型训练过程中，预训练语言模型的主干参数保持冻结，交通领域映射层的参数与交通流预测网络的参数共同参与优化，通过交通流预测误差的反向传播，对通用语义嵌入进行任务自适应校准，将通用文本语义逐步校准为更适合交通流预测任务的功能语义表征，使映射后的交通领域语义表征更适于反映交通节点之间的功能关联关系。
P079 [] 节点通用语义嵌入eisem、交通领域语义特征eitraffic可分别按如下方式计算，
